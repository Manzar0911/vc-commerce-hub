# Contributing to VC Commerce Hub

Thank you for your interest in contributing to **VC Commerce Hub**! 

### Guidelines:
1. **Explore Issues**: Before proposing changes or major features, check existing issues or create a new issue to discuss your ideas.
2. **Branching Strategy**: Create a feature branch off `main` (e.g. `feature/my-feature` or `fix/issue-description`).
3. **Coding Standards**: Adhere to .NET / C# coding standards, verify nullable checks, and ensure formatting matches `.editorconfig`.
4. **Testing**: Run all unit tests (`dotnet test`) before submitting a pull request.
5. **Submit Pull Request**: Open a clear PR detailing what was changed and why.
